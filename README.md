# Chelsea Scott — Personal Website

A personal portfolio site built with React, TypeScript, Tailwind CSS, and Vite. Showcases my background in AWS infrastructure engineering and my interest in the New Space sector.

## Features

- Hero section with intro and social links
- About section with skills and areas of interest
- Projects showcase
- Contact section
- Dark mode toggle
- Responsive design with Tailwind CSS

## Tech Stack

- **Framework:** React 19
- **Language:** TypeScript
- **Styling:** Tailwind CSS 4
- **Build Tool:** Vite 8
- **Testing:** Vitest + React Testing Library

## Getting Started

```bash
# Install dependencies
npm install

# Start the dev server
npm run dev

# Run linting
npm run lint

# Run tests
npm run test

# Build for production
npm run build

# Preview the production build
npm run preview
```
